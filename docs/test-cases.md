# 测试用例与结果

## 1. 测试范围

自动化测试覆盖：

- 用户注册、用户名冲突、会话 Cookie。
- 未登录访问拦截。
- 问卷所有权隔离。
- 四种题型及其校验。
- 单选与数字条件跳转。
- 多选“包含某选项”跳转。
- 跳跃题目的必答规则。
- 客户端提交未到达题目的非法答案。
- 发布、填写、幂等重试和重复提交。
- 聚合统计。

浏览器验收额外覆盖页面导航和交互。

## 2. 运行方式

在可用的 MongoDB 上执行：

```powershell
$env:TEST_MONGODB_URI = "mongodb://127.0.0.1:27017"
python -m unittest discover -s test -v
```

测试数据库名称随机生成，测试结束后自动删除。

第二阶段新增后实测使用 MongoDB 8.3 独立实例：

```text
Ran 17 tests in 4.272s
OK
```

## 4. 浏览器手工验收

实测环境：ChatGPT 内置浏览器，访问本地 `http://localhost:3000`。

### M01 登录与列表

1. 使用 `demo / Demo12345` 登录。
2. 检查浏览器控制台。

输入：演示账号。

输出：显示“我的问卷”、1 张已发布问卷卡片、回答数、截止时间。

结果：通过，控制台无错误。

### M02 编辑器

1. 点击问卷卡片的“编辑”。
2. 检查 6 道题目、选项、校验和两条跳转规则。
3. 确认已发布问卷的题目控件被禁用。

输入：无。

输出：题目结构、发布状态和分享链接正确显示。

结果：通过。

### M03 条件跳转与提交

1. 打开 `python seed.py` 创建的演示问卷链接。
2. 第一题选择“学生”。
3. 填写学校“计算机科学”。
4. 第三题选择“时间管理、编程实践”。
5. 年龄填写 `60`。
6. 填写建议并提交。

输出：

- 第一题后仍进入第二题。
- 第三题后进入第四题。
- 年龄 60 跳至第六题，跳过第五题。
- 最后一题按钮文字为“提交问卷”。
- 提交后显示“回答已提交”。

结果：通过。

### M04 统计

1. 打开问卷统计页。
2. 检查总回答数、题目数量、匿名标记。
3. 检查选项条形图、文本内容和平均值。
4. 切换“查看范围”。

输出：

- 总回答数 1。
- 单选题和年龄统计正确。
- 第五题显示 0 人回答。
- 第六题显示完整文本回答。

结果：通过。

### M05 响应式布局

在约 640 像素宽浏览器中检查首页、编辑页、填写页和统计页。

输出：主栏切换为单列，按钮和题目控件没有横向溢出；编辑页侧栏操作置顶。

结果：通过。

### M06 账号注册时间

1. 登录后查看“我的问卷”标题下方。
2. 运行 `python scripts/user_info.py <用户名>`。

输入：演示账号。

输出：页面与命令行都显示注册时间。

结果：通过。

### M07 跳转目标序号

1. 在草稿问卷末尾添加新题目。
2. 为前面题目添加跳转规则并展开目标下拉框。

输入：新建单选、多选或数字题。

输出：目标显示为“第 N 题 · 题目标题”，不再出现 `第NaN题`。

结果：通过。

### M08 新题默认必答

1. 打开任意草稿问卷。
2. 添加一道单选题。

输入：使用“＋ 单选题”按钮创建题目。

输出：“必答题”复选框默认选中。

结果：通过。

## 5. 已知测试边界

- 未做高并发压力测试；当前并发正确性主要由 MongoDB 唯一索引保证。
- 未做跨浏览器矩阵；已检查内置 Chromium 浏览器。
- 统计文本题返回当前阶段全部回答，数据量特别大时应增加分页或导出。
- 未接入邮件、验证码、第三方 OAuth 等外部服务。
- 题库暂未提供删除和版本合并。
- 跨问卷统计只汇总当前用户拥有的问卷。
