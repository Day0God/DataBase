### AI-01 初始需求与系统设计

Prompt，节选：

> 开发一个简化版的在线问卷系统，功能类似于“问卷星”或 Google Forms。系统应允许注册用户创建问卷，并通过 URL 分发问卷，其他用户可以填写问卷，系统可以统计问卷结果。
>
> 必须使用 MongoDB，不允许使用关系数据库，不允许用现成问卷系统框架。重点考察 MongoDB 数据库设计、后端程序设计、数据结构与业务逻辑建模、条件逻辑与跳转逻辑。

Result：

- 得到账号、问卷、题目、回答和统计的模块拆分。
- 得到 Flask API、MongoDB 集合、原生前端和测试目录的初始设计。
- 得到条件跳转和四种题型的数据结构。

修改：

- 改为本机已有的 Python + Flask + PyMongo，删除未运行的 Node 后端草稿。
- 保留原来的五个集合设计和通用跳转解释器，重新实现后端。

### AI-02 MongoDB Schema 与索引

Prompt，节选：

> MongoDB 设计要求（重点）：勿将所有数据存在一个集合；谨慎使用冗余设计；勿把逻辑写死在代码。须说明为什么这样设计，为什么不用关系数据库结构，为什么适合 MongoDB。

Result：

- 得到 `users`、`sessions`、`surveys`、`questions`、`submissions` 五个集合。
- 得到集合级 `$jsonSchema` 校验器。
- 得到用户名、问卷 slug、题目顺序、参与者去重和幂等提交索引。

修改：

- 题目与问卷拆开；选项和跳转只嵌入题目，不拆成独立集合。
- 回答中的答案数组嵌入 `submissions`，不重复保存完整问卷。
- 匿名问卷只保存 HMAC 去重键，不保存回答者用户 ID。
- 新增 `enforceOnce` 部分唯一索引，兼容“允许重复填写”开关。
- 新增 `idempotencyKey` 唯一索引，处理双击和网络重试。

相关代码：

### AI-03 条件跳转与答案校验

Prompt，节选：

> 用户希望问卷可以根据回答情况跳转到不同题目。根据单选结果、多选结果、数字填空内容跳转。填写问卷时系统应自动跳到对应题目。

Result：

- 得到 `option_is`、`contains` 和多组数字比较运算符。
- 得到浏览器端即时校验和服务端重新遍历的两层校验。
- 得到“第一条命中规则优先”的执行顺序。

修改：

- 禁止目标题目早于当前题目，避免 A→B→A 的无限跳转。
- 被跳转规则跳过的必答题不要求回答。
- 服务端拒绝提交未到达题目的额外答案。
- 数字题支持最小值、最大值、整数限制；文本题支持字符长度限制。

相关代码：

- `app/validation.py`
- `public/js/survey.js`

## 4. AI 出现过的错误与处理

| 问题 | 来源 | 影响 | 处理 |
| --- | --- | --- | --- |
| 初版选择 Node.js 依赖 | AI 技术选型 | 当前环境无法安装依赖，项目不能直接运行 | 改为本机已有的 Flask + PyMongo，并删除未运行草稿 |
| 跳转目标显示 `第NaN题` | AI 前端实现 | 新题没有同步 `order` | 渲染前统一重建顺序，使用实际数组位置显示编号 |
| 关闭问卷无法重新发布 | 用户验收 | 保存流程无条件 PUT 题目，被历史回答保护拦截 | 拆分设置保存和题目保存，题目锁定时只更新设置 |
| 预览链接指向 `#` | AI 前端实现 | 无法从编辑器预览问卷 | 发布后设置真实 `/survey/<slug>` 地址 |
| 测试路径假设错误 | AI 编写测试 | 测试把实际到达的题目当成被跳过题目 | 修正路径前提后重新运行测试 |
| 命令行脚本导入失败 | AI 新增工具 | `python scripts/user_info.py` 找不到 `app` 包 | 将项目根目录加入模块搜索路径 |
| 命令行中文乱码 | AI 新增工具 | Windows 终端输出不可读 | 将标准输出重新配置为 UTF-8 |

## 5. 人工反馈与项目决策

实际对话中，项目负责人直接提出并确认了以下需求修正：

- 注册时间必须在界面可见，并给出后端查看方式。
- 跳转目标不能显示 `NaN`。
- 已有回答的关闭问卷必须能够重新开放。
- 新建题目默认必答。

AI 根据这些反馈完成代码修改和回归测试。项目负责人还通过实际页面操作发现了前端保存流程的问题，这说明仅靠“代码看起来正确”不足以证明业务可用。

项目中实施的关键设计决策包括：

- 问卷、题目、回答分开存储，选项和跳转随题目存储。
- 跳转只能指向后续题目。
- 浏览器和服务端都校验，但服务端最终裁定。
- 发布中禁止改题，已有回答后禁止改题。
- 匿名与去重通过 HMAC 技术键兼容。
- 提交使用幂等键和数据库部分唯一索引。
